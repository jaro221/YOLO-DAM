GOAL: Create segmentation dataset with visualization for quality check

================================================================================
STEP 1: GENERATE SEGMENTATION DATASET (30-80 min)
================================================================================

Command:
  python prepare_dataset_segmentation.py

Input:
  D:\Projekty\2022_01_BattPor\DATA_DEF\YOLOv8\dataset
  ├── images/train/ (3,104 images)
  └── labels/train/ (3,104 detection labels)

Process:
  1. Load YOLO-DAM v3 model (C3k2 backbone)
  2. For each image:
     - Load detection bboxes (true labels)
     - Extract patches
     - Run through autoencoder
     - Compute reconstruction error
     - Apply Gaussian blur (σ=2.0)
     - Threshold at 70th percentile
     - Convert to polygon
  3. Split: 80% train / 20% val
  4. Copy images to output directory

Output:
  D:\Projekty\2022_01_BattPor\2025_12_Dresden\DATASET_SEG/
  ├── images/
  │   ├── train/      (~2,480 images)
  │   └── val/        (~620 images)
  ├── labels/
  │   ├── train/      (~2,200 polygon labels)
  │   └── val/        (~550 polygon labels)
  ├── data.yaml       (YOLO config)
  └── DATASET_INFO.txt (statistics)

Expected results:
  ✓ ~2,480 train images copied
  ✓ ~620 val images copied
  ✓ ~2,200 train masks generated (~88% coverage)
  ✓ ~550 val masks generated (~88% coverage)
  ✓ Total objects segmented: ~2,750

Time: ~30-80 minutes (3,104 images × 1-2 sec/image with autoencoder)

Monitor:
  Watch console output for progress
  Should see: "50/500 images processed", "100/500", etc.

TROUBLESHOOTING
================================================================================

Problem: Script runs very slow
→ Normal! Processing through autoencoder takes time
  Expected: 60-80 minutes for 3,104 images
  Patience: ☕ (make coffee, it's worth the wait)

Problem: Very few masks generated
→ Check:
  1. Source dataset has detection labels?
  2. Autoencoder running properly?
  3. Try lowering THRESHOLD_PERCENTILE (70 → 60)

Problem: Visualizations look bad
→ Options:
  1. Adjust GAUSSIAN_SIGMA in prepare_dataset_segmentation.py
  2. Adjust THRESHOLD_PERCENTILE
  3. Re-run generation with new parameters

Problem: Out of memory
→ Solution:
  1. Check model weights loaded
  2. Reduce batch operations
  3. May need to process in chunks

Problem: Can't find visualizations folder
→ Check: D:\Projekty\2022_01_BattPor\2025_12_Dresden\DATASET_SEG\visualizations/
